    How it is measured

      What to keep in mind

      • One machine runs PHP, the database and the load generator, with no network latency to the database. Absolute numbers will differ on a server; compare the APIs, not the values. On a remote database every additional query costs a round trip, so per-row loading falls further behind.
      • Payloads differ: tca_api and t3api return Hydra JSON-LD with @id, @type and pagination links; sg_apicore leaves out categories.
      • One dataset: 10,000 articles with 10 authors, 15 tags and 8 categories, 2–4 tags and 1–3 categories per article.
      • Each package is written the way its API documents it. Where an API cannot do part of the task, the gap is shown above instead of worked around.
