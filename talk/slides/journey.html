Warum noch eine API-Extension?

Wie es zu tca_api kam

01

Statische Seiten

Static File Cache ist extrem performant, also kein USER_INT

02

Web Components

Dynamische Daten-Elemente überall platzieren

03

APIs

Liefern die dynamischen Daten, erste Wahl: t3api

04

Kalter Cache

Häufige Änderungen, im Extremfall tausende Datensätze im Client: Serialisierung wird zur Grenze

05

tca_api

So einfach wie t3api, ohne Limit bei der Performance

Das Ziel: einfach konfigurieren und schnell ausliefern, beides zugleich.
